# 素材・情報チェックリスト

サイトを「準備中」から本物にするために、晴れ人さん側で集めてもらえると嬉しい素材の一覧です。
全部いっぺんに揃えなくても大丈夫。**揃ったものから私（Claude）に渡してくれれば順に反映します。**

## 1. 写真 📷（あると一気に魅力アップ）

- [ ] 宵祭りの出店の様子（屋台・お客さん・メンバーなど）
- [ ] 助川御神幸祭でみこしを担いでいる様子
- [ ] メンバーの集合写真（あれば）
- [ ] トップ（ヒーロー）に大きく使える、雰囲気の良い1枚

> メモ: 写真は人物の顔が写る場合、本人の許可をとってから掲載しましょう。
> 撮影者がいる場合は掲載OKかも確認を。

## 2. 連絡先 📨（「声をかける」ために必須）

下のうち、**公開してよいものだけ**でOKです。

- [ ] 問い合わせ用メールアドレス
- [ ] SNSアカウント（Instagram / X / Facebook / LINEオープンチャット など）
- [ ] 問い合わせフォームを使いたい場合はその旨（無料で設置できます）

## 3. 団体の言葉 ✍️（任意・あれば深みが出る）

- [ ] キャッチコピーの希望（今は「楽しそう、おもろそう。そう感じた人が、動く。」を仮で使用）
- [ ] 団体の成り立ち・きっかけのエピソード
- [ ] 代表者やメンバーの紹介文（出したい場合）
- [ ] 「晴れ人」という名前の由来（あれば載せたい）

## 4. ロゴ・シンボル 🎨（任意）

- [ ] 既にロゴがあれば画像データ（PNG / SVG など）
- [ ] なければ、文字だけのシンプルなロゴをこちらで用意できます

## 5. 今後のために（おいおいでOK）

- [ ] 独自ドメインを取りたいか（例: harebito.jp など）
- [ ] 載せたい「今後のイベント」の予定があれば

---

### 渡し方について

写真やテキストは、このチャットに貼ってもらうか、リポジトリに置いてもらえれば反映します。
「これ載せたい」と一言添えてくれれば、配置やトリミングはこちらで調整します。
