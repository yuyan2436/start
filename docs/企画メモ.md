# 晴れ人 ウェブサイト 企画メモ

このファイルは「何のために・どんなサイトを作るか」を一枚にまとめたものです。
迷ったらここに立ち返ります。更新したくなったら気軽に書き換えてOK。

## 団体について

- **団体名**: 晴れ人（はれびと）
- **拠点**: 茨城県日立市
- **性格**: 地域密着のイベントグループ。決まった活動方針はなく、「楽しそう・おもろそう」と
  感じた人が善意で集まって動く。
- **これまでの活動**
  - 助川鹿嶋神社の「宵祭り」（縁起の良いお祭り）で出店
  - 7年に一度の「助川御神幸祭」でみこしを担ぎ街を練り歩き
- **目標**
  1. まずは地域の行事に積極的に参加する
  2. ゆくゆくは、さまざまな行事から「声がかかる」組織になる

## サイトの目的（最優先）

**活動を見せて、「うちの行事にも来てほしい」と声がかかる入口にする。**

→ そのため、トップページは「どんな団体か」「何をしてきたか」がひと目で伝わり、
最後に「声をかける（連絡する）」へ自然につながる構成にしている。

## 運用方針（決定事項）

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 技術構成 | 素のHTML / CSS（ビルド不要） | 壊れにくく、誰でも・いつでも更新しやすい |
| 更新の担当 | Claude に依頼して反映 | CMS等の仕組みが不要でシンプル |
| ホスティング | GitHub Pages（無料）を予定 | コスト0で公開できる |
| ドメイン | まずは無料の初期ドメイン。独自ドメインは将来検討 | こだわらない方針のため段階的に |

## ページ構成（現状）

今は **1ページ完結（ランディングページ）** で始める。情報量が増えたらページを分割する。

1. **ヒーロー** … 団体名・キャッチコピー・場所
2. **晴れ人とは（About）** … どんな団体か
3. **これまでの活動（Works）** … 宵祭り出店 / 御神幸祭みこし
4. **これから（Future）** … 目標2ステップ
5. **声をかける（Contact）** … 連絡先

## デザインの方向性

- テーマは「晴れ」。明るい**朱色 × 生成り（きなり）**で、お祭り・縁起の良さを表現
- 見出しは明朝体（和の雰囲気）、本文はゴシックで読みやすく
- スマホでもきれいに見えるレスポンシブ対応

## これから足していきたいこと（アイデア）

- 活動写真の追加（宵祭り・御神幸祭の実際の写真）
- 連絡先（メール / SNS）の設定
- ロゴ・シンボルマークの作成
- 今後のイベント告知エリア
- SNS（Instagram など）との連携
- 独自ドメインの取得
