# 晴れ人（はれびと）ウェブサイト

茨城県日立市の地域イベントグループ「晴れ人」の公式サイトです。

## 概要

- **技術構成**: 素のHTML / CSS（ビルド不要・フレームワークなし）
- **公開方法**: GitHub Pages（無料）を予定
- **更新**: Claude に依頼して反映

## ファイル構成

```
.
├── index.html            … トップページ（1ページ完結）
├── css/
│   └── style.css         … サイト全体のスタイル
├── images/               … 写真・画像の置き場
└── docs/
    ├── 企画メモ.md        … 何のために何を作るかのまとめ
    └── 素材チェックリスト.md … 集めてほしい写真・情報の一覧
```

## ローカルで確認する

`index.html` をブラウザで開くだけで表示できます。
（簡易サーバーで見たい場合は、このフォルダで `python3 -m http.server` を実行し
`http://localhost:8000` を開く）

## 公開（GitHub Pages）

リポジトリの Settings → Pages で、Branch を公開用ブランチ／`/ (root)` に設定すると
`index.html` がそのまま公開されます。

## これから

`docs/企画メモ.md` の「これから足していきたいこと」を参照。
まずは `docs/素材チェックリスト.md` の写真・連絡先が揃うと一気に本物になります。
